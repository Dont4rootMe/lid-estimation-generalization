# Единая точка входа для агентов

Эта папка хранит общий контекст проекта. Она не заменяет предметные документы,
а задаёт порядок их чтения, фиксирует текущее состояние и предотвращает
расхождение рукописи, теории и экспериментов.

Последнее содержательное обновление: **2026-08-31**.

## Что читать

Для любой задачи:

1. корневой [`AGENTS.md`](../../AGENTS.md);
2. [`PROJECT_STATE.md`](PROJECT_STATE.md);
3. [`WORKFLOW.md`](WORKFLOW.md);
4. для анализа выполненных экспериментов —
   [`../EXPERIMENT_RESULTS.md`](../EXPERIMENT_RESULTS.md);
5. для запуска экспериментов — [`RUNBOOK.md`](RUNBOOK.md).

Дополнительно:

- теория, статья, related work или формулы —
  [`THEORY_CONTRACT.md`](THEORY_CONTRACT.md), затем `paper/ru/README.md` и
  `paper/ru/TERMINOLOGY.md`;
- экспериментальный дизайн — [`../EXPERIMENT_PROTOCOL.md`](../EXPERIMENT_PROTOCOL.md)
  и [`../MODEL_MATRIX.md`](../MODEL_MATRIX.md);
- реализация runner — [`../ARCHITECTURE.md`](../ARCHITECTURE.md);
- learned-модели и артефакты — [`../LEARNED_BUNDLES.md`](../LEARNED_BUNDLES.md);
- аффинное согласование потоков — [`../FM_CAMPAIGN.md`](../FM_CAMPAIGN.md);
- normalizing-flow ablation и readout follow-up —
  [`../NF_CAMPAIGN.md`](../NF_CAMPAIGN.md);
- мосты Шрёдингера —
  [`../SCHRODINGER_BRIDGE_PILOT.md`](../SCHRODINGER_BRIDGE_PILOT.md);
- датасеты и воспроизводимость — [`../UPSTREAM_AUDIT.md`](../UPSTREAM_AUDIT.md)
  и [`../GENERATED_E3_E4.md`](../GENERATED_E3_E4.md);
- история принятых решений — [`DECISIONS.md`](DECISIONS.md).

## Иерархия источников истины

1. Для точной формулировки теоремы каноничен соответствующий `.tex`-файл в
   `paper/ru/sections/`; `THEORY_CONTRACT.md` задаёт обязательные границы
   интерпретации.
2. Для фактически исполняемого эксперимента каноничны код, resolved Hydra
   config и тесты. Документы объясняют контракт и должны обновляться вместе с
   его изменением.
3. Для текущего редакционного состояния каноничен `PROJECT_STATE.md`.
4. При противоречии нельзя молча выбирать удобную версию. Нужно проверить
   реализацию или доказательство, сообщить о расхождении и синхронно исправить
   затронутые документы.

## Что сюда не помещать

- полный текст приватной рукописи;
- секреты, токены, абсолютные пути к приватным checkpoint;
- неподтверждённые экспериментальные числа;
- длинные журналы команд и временные заметки одного запуска.

Для нового устойчивого решения используется `DECISIONS.md`; для подробного
предметного контракта создаётся отдельный документ в `docs/` и добавляется в
эту карту.
