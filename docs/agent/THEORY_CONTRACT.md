# Теоретический контракт статьи

Документ фиксирует математические и новизновые границы, которые нельзя
расширять редакционной формулировкой.

## Центральный вопрос

Какие проверяемые свойства семейства распределений или транспортов вблизи
распределения данных гарантируют, что LID в точке восстанавливается из
производной плотности, апостериорного отклика либо модельного поля?

Статья не доказывает, что LID можно извлечь из любой генеративной модели.

## Механизм K: предельный канал

Для известного физического масштаба `eps -> 0`, ненулевого полного
`d`-однородного касательного предела и контролируемой предельной формы ядра
основной закон имеет вид

```text
rho_eps(x) = eps^(d-D) (C_x + o(1)),
D + d/d(log eps) log rho_eps(x) -> d.
```

Обязательные элементы утверждения:

- масштаб `eps` физически определён, а не является произвольным временем;
- требуется полный однородный касательный предел и взвешенный контроль хвостов
  и масштабной производной;
- ветвь плотности применима к общим однородным касательным мерам;
- след якобиана апостериорного условного среднего без поправки восстанавливает
  `d` для плоской касательной геометрии;
- на односторонних границах response-ветвь имеет ненулевое смещение, тогда как
  полная density-ветвь содержит необходимую поправку;
- при радиально-симметричном ядре матричный предел восстанавливает касательное
  пространство в плоском случае.

Геометрический scope включает внутренние точки гладких `C^1`-многообразий,
регулярные точки спрямляемых мер почти всюду и однородные конусы при
дополнительном контроле хвостов. Простого существования числовой pointwise LID
недостаточно для всей теоремы.

## Механизм T: калиброванный транспорт

Класс T является отдельным достаточным механизмом. Он предполагает семейство
диффеоморфизмов с контролируемым предельным вырождением, постоянным рангом
локального предельного отображения и известной скоростью поперечного сжатия.
Нормированный якобиан скорости восстанавливает проектор на схлопывающиеся
направления, а его дополнение — касательный проектор.

Нельзя выводить этот результат только из determinant scaling или точечного
сжатия якобиана: без геометрического предела на фиксированной окрестности
возникают контрпримеры с локальным pinch на множестве нулевой массы.

## Допустимые модельные адаптеры

- **Диффузия:** восстановление известного FLIPD через гауссовский канал;
  диффузионная ветвь сама по себе не является новым вкладом.
- **Независимое аффинное FM:** адаптер класса K после калибровки
  `eps = beta/alpha`; нативные velocity/divergence формулы требуют именно
  независимого аффинного интерполянта. Произвольные coupled/nonlinear FM сюда
  автоматически не входят.
- **Мост Шрёдингера:** для сингулярного manifold-supported терминального
  маргинала используется обобщённая смесь броуновских мостов либо явно
  контролируемый сглаженный предел. Классический finite-KL Brownian bridge с
  сингулярным концом нельзя молча предполагать существующим.
- **Scale-conditioned NF:** точная ветвь правдоподобия является
  дифференциальной реализацией LIDL для калиброванного пути сглаженных
  плотностей.
- **Сингулярный NF/CNF:** только отдельный класс T с известной поперечной
  скоростью. Фиксированный регулярный обратимый NF имеет полноразмерную
  локальную размерность `D`.

VAE, произвольные стохастические интерполянты, не-броуновские мосты и другие
архитектуры являются направлениями расширения до появления точной предельной
нормальной формы и модельного тождества.

## Границы новизны

Не заявлять как новые:

- использование NF в LIDL;
- первое применение FM к FLIPD;
- первую гауссовскую унификацию LID-методов;
- формулы Твиди, уравнение непрерывности и известные конечномасштабные
  covariance--Jacobian/risk--divergence тождества;
- тождества терминального дрейфа и условного среднего для SB;
- общий факт невозможности представить сингулярную меру фиксированным
  регулярным NF.

Ближайшие работы и различия подробно зафиксированы в
`paper/ru/sections/02_related_work.tex` и `references.bib`. Безопасная
формулировка вклада: единая организация через калиброванный предельный канал,
LID-следствия и точные адаптеры при явных условиях, плюс отдельная граница
идентифицируемости для транспортов.

## Статистические ограничения

Теоремы сформулированы на уровне истинных распределений и точных полей. Малая
ошибка field-matching loss, likelihood или KL не контролирует автоматически
divergence, Hessian или производную по масштабу. Для эмпирической меры
инфинитезимальный предел атомарен; manifold LID требует мезоскопического режима,
где ширина канала больше межвыборочного расстояния и меньше масштаба кривизны.
