# Журнал решений

Здесь фиксируются устойчивые решения, влияющие на работу следующих агентов.
Подробные доказательства и протоколы остаются в предметных документах.

## Состояние, зафиксированное к 2026-08-30

### Приватное расположение рукописи

Исходники находятся в `paper/`, а не в `docs/paper/`. Каталог целиком исключён
из Git, чтобы рабочий текст не попадал в reviewer-facing историю. Публичные
документы могут описывать контракты, но не должны копировать рукопись целиком.

### Русская версия является рабочей

Содержательная переработка ведётся в `paper/ru/`. Английская версия временно
заморожена. Разделы хранятся в отдельных `.tex`, приложения — в
`sections/appendix/`; `main.tex` управляет только сборкой и порядком импортов.

### Редакционная фаза

В текущем превью подключены аннотация и введение. Введение начинается с
локально допустимых вариаций объектов, завершает первый абзац эмпирическим
примером латентной диффузии и только затем вводит гипотезу многообразия. После
сокращения сохранён отдельный блок «Основные результаты».

### Два механизма вместо обещания универсальности

Класс K предельных вероятностных каналов является основным объединяющим
механизмом. Класс T калиброванных вырождающихся транспортов сформулирован
отдельно. Формулировка «любая генеративная модель оценивает LID» запрещена как
математически неверная.

### Уровни экспериментальных свидетельств

Population/oracle проверки подтверждают формулы и finite-sample target.
Learned experiments измеряют ошибки аппроксимации, производных и выбора
масштаба. Эти уровни не объединяются и не подменяют друг друга.

### Production orchestration и локальный bundle

Актуальный production runner глобальной кампании — восьми-H100 cell-DAG в
`experiments.global_parallel`; последовательный single-A100 путь сохранён как
legacy. Локальный консолидированный bundle содержит 2106 analysis-ready строк,
но исключён из Git и не содержит тяжёлого training evidence. Поэтому его числа
могут использоваться только после проверки manifest/SHA и не считаются
автоматически доступными другому агенту.

## 2026-08-31 — Каноническая таксономия learned-study

Контекст: завершённая baseline campaign, FM factorization и NF follow-up ранее
описывались в разных operational артефактах. Из-за этого 390 baseline
trainings, 78 supplemental trainings, 13 logical variants и 2106 CSV rows можно
было ошибочно принять за одно и то же количество экспериментов.

Решение: `docs/EXPERIMENT_RESULTS.md` является единой tracked-точкой входа для
выполненной study, а `docs/NF_CAMPAIGN.md` — предметным NF-контрактом. Десять
baseline entries называются configurations/variants; шесть FM entries являются
3 × 2 факториалом одного independent-affine-flow family. Consolidated bundle
сохраняет baseline точным byte prefix и добавляет только три проверенных NF
logical variants.

Последствия: scope содержит 35 canonical cells; headline scoring использует
test, reported primary readout и 33 nontrivial cells. E1/E5 anchors не считаются
самостоятельными scoring cells; E1 reference anchor остаётся нулевой границей
AUC. У baseline/FM primary объявлен заранее; frozen NF OLS5 является
validation-selected logical variant, даже если его test rows confirmatory.
Generated E3/E4, FM alternate readouts и test-oracle показываются отдельно.
Пустые MAE/reference поля читаются по analysis schema, а не как failed eval.

Затронутые файлы: `docs/EXPERIMENT_RESULTS.md`, `docs/NF_CAMPAIGN.md`,
`docs/FM_CAMPAIGN.md`, `docs/MODEL_MATRIX.md`,
`docs/EXPERIMENT_PROTOCOL.md`, `docs/LEARNED_BUNDLES.md`,
`docs/agent/README.md`, `docs/agent/PROJECT_STATE.md`,
`docs/agent/RUNBOOK.md`.

## 2026-09-08 — Исправление координации GPU preflight
