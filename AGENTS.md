# Инструкции для агентов

Перед любой содержательной работой в этом репозитории обязательно прочитать
[`docs/agent/README.md`](docs/agent/README.md) и указанные там документы для
своего типа задачи. Не следует восстанавливать состояние проекта по памяти из
предыдущих диалогов: источником истины служат файлы репозитория и актуальная
карта состояния.

## Обязательные правила

1. Русская рукопись в `paper/ru/` является рабочей содержательной версией.
   Английская версия пока не синхронизируется автоматически.
2. `paper/` намеренно исключена из Git. Не добавлять её принудительно и не
   переносить текст рукописи в отслеживаемые файлы без прямого запроса.
3. Теоретические заявления должны соблюдать границы из
   `docs/agent/THEORY_CONTRACT.md`. В частности, не заявлять применимость к
   произвольной генеративной модели.
4. Перед редактированием проверять актуальное содержимое файла и сохранять
   несвязанные изменения пользователя. Подагенты по умолчанию проводят аудит и
   возвращают предложения; один назначенный агент интегрирует правки.
5. После решения, меняющего сюжет статьи, область теоремы, экспериментальный
   протокол или файловую структуру, основной агент обновляет соответствующий
   документ в `docs/agent/` и запись в `docs/agent/DECISIONS.md`.
6. Рукопись, код и эксперименты имеют разные уровни доказательности. Наличие
   формулы или конфигурации не означает наличия обученного результата.
